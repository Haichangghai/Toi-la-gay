        Lấy file dữ liệu tin nhắn từ TikTok

        Bạn chỉ cần làm một lần: gửi yêu cầu trong app, chờ TikTok chuẩn bị file, tải về rồi thả vào trang này.

        Cần có
        App TikTok trên điện thoại
        Thời gian chờ
        Từ vài giờ đến vài ngày
        File nhận được
        Một file .zip
        1. 1

          Mở Cài đặt và quyền riêng tư

          Vào Hồ sơ, chạm biểu tượng ba gạch ở góc trên bên phải, rồi chọn Cài đặt và quyền riêng tư.

          Hồ sơ›Menu ba gạch›Cài đặt và quyền riêng tư
          Hồ sơ
          Cài đặt và quyền riêng tư
        2. 2

          Vào Tải xuống dữ liệu của bạn

          Chọn Tài khoản, rồi chọn Tải xuống dữ liệu của bạn.

          Tài khoản›Tải xuống dữ liệu của bạn
          Tài khoản
          Tải xuống dữ liệu của bạn
        3. 3

          Chọn dữ liệu Tin nhắn

          Ở tab Yêu cầu dữ liệu, chọn mục Tin nhắn (có thể hiện là Tin nhắn trực tiếp). Nếu không thấy mục này, chọn Tất cả dữ liệu, file sẽ nặng hơn.

          Chỉ chọn Tin nhắn thì TikTok chuẩn bị file nhanh hơn và file nhẹ hơn.

          Tải xuống dữ liệu
          Yêu cầu dữ liệuTải dữ liệu xuống
          Tin nhắn
        4. 4

          Chọn JSON rồi gửi yêu cầu

          Chọn định dạng JSON (khuyên dùng) hoặc TXT, trang này đọc được cả hai. Sau đó chạm Yêu cầu dữ liệu.

          JSON›Yêu cầu dữ liệu
          Định dạng tệp
          JSONTXT
          Yêu cầu dữ liệu
        5. 5

          Chờ TikTok chuẩn bị file

          Thường mất từ vài giờ đến vài ngày. Khi file sẵn sàng, TikTok báo trong hộp thư thông báo của app.

          Đang chuẩn bị file
        6. 6

          Tải file về máy

          Quay lại Tải xuống dữ liệu của bạn, mở tab Tải dữ liệu xuống và chạm Tải xuống. Bạn nhận được một file .zip, không cần giải nén.

          File chỉ được giữ để tải trong khoảng 4 ngày. Hãy tải ngay khi có thông báo.

          Tải xuống dữ liệu

          Tải xuống
        7. 7

          Thả file vào trang này

          Quay lại phần Đếm tin nhắn và thả file .zip vào vòng tròn. Tổng số tin nhắn hiện ra ngay.

          .zip

        Câu hỏi thường gặp

        Không. Trang này đọc và đếm ngay trong trình duyệt của bạn, không có bước nào tải file lên máy chủ. Bạn có thể tắt mạng sau khi mở trang, việc đếm vẫn chạy bình thường.

        Thường là do lúc yêu cầu dữ liệu bạn chưa chọn mục Tin nhắn. Hãy yêu cầu lại và chọn mục này (hoặc chọn Tất cả dữ liệu). Nếu bạn đã giải nén, hãy chọn file .json hoặc .txt chứa tin nhắn thay vì chọn cả thư mục.

        Hầu hết trình duyệt mới đọc được file .zip trực tiếp. Nếu trình duyệt của bạn báo chưa hỗ trợ, hãy giải nén file trong app Tệp (iPhone) hoặc Files (Android), rồi chọn file .json hoặc .txt bên trong.

        Xem lại tin nhắn

        Chọn một người và một ngày, trang sẽ phát lại đoạn hội thoại hôm đó như đang nhắn thật.
